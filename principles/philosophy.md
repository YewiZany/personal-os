# Philosophy

## AI should reduce friction, not agency

Delegate repeated work. Keep the choices and experiences that build judgment. Saving effort is useful only if the user retains the ability to direct and assess the work.

## Planning is not output

A plan earns its place by changing the next action. Once no new decision remains, more planning spends attention without testing reality.

## Capture without context switching

An idea can be valuable without being urgent. Inbox preserves the possibility while protecting the work already chosen.

## Output over occupied time

A working page, a tested assumption, a clearer explanation or an observed failure is evidence. A full calendar is not.

## Continuity over daily reinvention

Tomorrow First Move turns a day's ending into the next day's beginning. Progress compounds when it survives the boundary between sessions.

## A successful AI system creates a more capable user

The long-term measure is whether the user can decide, start, understand and create with less assistance. A system that increases dependence has missed its purpose.
