# Contributing

Useful contributions make the first real action easier:

- An unclear instruction and a concrete replacement.
- A fictional example showing a missing workflow case.
- An observed first-time setup failure, with no personal data.
- A prompt change that preserves user judgment and truthful reporting.

For onboarding feedback, report the step, what you expected, what happened and whether you reached a first action. If you measured setup time, distinguish active setup from account registration or authorization delays.

Keep English and Chinese README behavior aligned. Keep field names and status options aligned with the schema documents. Run a relative-link check and a privacy review before submitting.

v0.1 stays documentation-first. Discuss new fields, adapters or automation before adding them. Do not submit private profiles, real day logs, credentials or screenshots containing unrelated personal information.

No test framework or dependency installation is required for documentation changes.
