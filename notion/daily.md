# Daily

Use the [setup field table](setup.md#daily) and [blank page body](daily-entry.md).

One record per local calendar day. Reuse today's record if another work conversation starts.

| Field | Type | Meaning |
| --- | --- | --- |
| Day | Title | YYYY-MM-DD label. |
| Date | Date | The user's local date. |
| Energy | Select | Low / Normal / High; optional subjective report. |
| Main Project | Relation to Projects | The project for the current main outcome. |
| Main Outcome | Text | What should exist or change today. |
| Actual Output | Text | What demonstrably happened. |
| Friction | Text | What affected progress. |
| Tomorrow First Move | Text | One specific starting action. |
| Closed | Checkbox | Daily review and handoff completed. |

Energy is not a health score. Do not infer a value from sleep duration alone.

Personal Notes in the body is a low-friction input area: completed action, result and blocker. Report there or in the conversation. The AI should reconcile notes with the summary instead of making you repeat them.

Before Closed is checked:

1. Actual Output records the actual result, including “no main outcome completed” when that is true.
2. Friction is captured, or explicitly “none significant.”
3. Tomorrow First Move is executable; if tomorrow is an intentional rest day, state that and the first move on returning.
4. Related project stages and Next Action are reconciled; loose ideas are captured.

A day can close without achieving its intended Main Outcome. Honesty and continuity matter more than a success label. An individual task's completion is written in the notes; it does not set Closed.

中文：Daily 不是流水账。正文个人记录用于低摩擦汇报，字段用于总结和交接。一天没完成主线也可以如实收尾；Closed 不表示单项任务完成。
