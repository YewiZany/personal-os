# Inbox

Use the [setup field table](setup.md#inbox).

| Field | Type | Meaning |
| --- | --- | --- |
| Item | Title | One clear sentence. |
| Type | Select | Idea / Task / Question / Explore / Later |
| Status | Select | New / Converted / Archived |
| Related Project | Relation to Projects | Optional connection to a project in this copy. |
| Created | Created time | Automatic. |

Idea is a possibility; Task is an action candidate; Question needs an answer; Explore is deliberate curiosity; Later is explicitly deferred.

Capture briefly. Resume the current work. Review when an item becomes relevant or in a short chosen review; the inbox is not another daily workload.

Before converting an item, decide whether it belongs to an existing project's Next Action or a genuinely chosen new project. Do not turn every idea into an Active project.

中文：收下不代表现在就做。Converted 表示已经变成具体行动，Archived 表示明确暂不处理，均不等同于删除页面。
