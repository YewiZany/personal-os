# Projects

Use the [setup field table](setup.md#projects) to build this database.

Projects contains work you have actually chosen to pursue. It is not a wishlist.

| Field | Type | Meaning |
| --- | --- | --- |
| Project | Title | A recognizable project name. |
| Status | Select | Active / Slow / Paused / Done |
| Area | Select | Product / Language / Technology / Study / Creative / Life / System |
| Current Stage | Text | What is already true. |
| Next Action | Text | The first action when reopening. |
| Deadline | Date | An actual external or chosen deadline, otherwise empty. |
| Last Updated | Last edited time | Automatic edit timestamp, not proof of substantive progress. |

Active means currently pursued; Slow means light maintenance; Paused means intentionally suspended; Done means the current project goal has been met.

“Work on portfolio” is not a Next Action. “Open the homepage at phone width and record the first broken layout” is.

Update after meaningful progress, a blocker or a priority change. Do not mistake a changed Last Updated value for evidence that neglected work advanced.

Current Stage describes evidence; Next Action describes future work. Keep them separate.

中文：保存实际选择推进的项目。阶段写已经发生的事实，下一动作写回来能直接做的事。自动编辑时间不能证明项目真的有进展。
