# Shutdown

Trigger: the user signals that the workday is ending. Aim for a brief handoff, not a long diary.

1. Read available conversation evidence and Personal Notes.
2. Draft Actual Output, Friction and one Tomorrow First Move.
3. Ask for important omissions or corrections. Do not invent work outside the available evidence.
4. Save the Daily fields, update related Projects' stage and Next Action, and capture loose Inbox items.
5. Set Closed true only after the required updates succeed; verify the handoff.
6. Say that the day is closed and stop opening large new topics.

If a required write fails, keep Closed false and give the unsaved update to the user.

Manual route: the user fills the same fields and project actions, then checks Closed. At the next work turn, the AI reads and reconciles that record. A missed outcome may still be closed honestly.

中文：收尾由已有证据起草，用户只需纠正和补充。保存交接信息后才勾 Closed；单项任务完成不触发整天关机。
