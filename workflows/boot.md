# Boot

Purpose: carry existing progress into one action, in a few minutes.

1. Read today's Daily if present, the latest previous day, Closed and Tomorrow First Move. Read current projects, real deadlines and relevant Inbox items.
2. If today is already underway, resume its current stage. If yesterday was unclosed, repair the handoff briefly.
3. Confirm only missing context: subjective energy, obligations, desired progress, unresolved work and the resisted action.
4. Choose one observable Main Outcome. Add one or two small maintenance items when appropriate.
5. State the completion check and the first action. Save the intention when possible, then start.

First run: there may be no yesterday. Start from one real project and its Next Action.

Exit condition: the user knows what to do first and is beginning it. A comprehensive daily plan is not required.

中文：先读已有记录，简短确认现实约束，然后确定一个成果和第一动作。当天已开始就承接，不重新开一轮全天规划。
