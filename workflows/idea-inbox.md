# Idea → Inbox

During a chosen task, the user says:

> I want to make a video about AI coding.

If it does not need attention now:

1. Compress it: “Video idea about AI coding.”
2. Set Type Idea, Status New, and optionally Related Project.
3. Save the record. If saving fails, label a draft and say it is not yet stored.
4. After success: “Captured to Inbox. Return to the homepage deployment.”

An idea is allowed to remain an idea. Capturing it does not create a deadline or an Active project.

If it is genuinely urgent or the user explicitly chooses a new priority, reassess the main outcome and leave a next action for the interrupted project.

中文：先判断是否必须现在处理，通常压缩成一句、存入 Inbox、回到主线。只有保存成功才能说“已收下”。
