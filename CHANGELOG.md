# Changelog

## v0.1.0

First experimental release:

- English and Simplified Chinese onboarding.
- Core and minimal prompts with a separate blank User Profile.
- Boot, Execution, Idea Inbox and Shutdown protocols.
- Notion schemas and a complete manual setup path.
- Fictional examples and a blank Daily page body.
- Personal Notes for reporting once; Closed reserved for daily handoff.
- Privacy guidance, MIT license and contribution boundaries.

No app, CLI, backend, synchronization service or alternate-store adapter.
The approximately 15-minute setup is a design target awaiting user observation.
